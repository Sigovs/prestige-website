# Prestige Website — Creative Direction

Goal: redesign index_3.html into a premium luxury automotive experience.

The site should feel:
- cinematic
- editorial
- expensive
- restrained
- confident
- modern luxury, not generic dealership

Avoid:
- generic dealership templates
- random gradients
- overused animations
- too many font sizes
- cluttered sections
- cheap glowing effects
- inconsistent spacing

Design principles:
- strong hierarchy
- generous spacing
- dark luxury atmosphere
- champagne / warm metallic accents
- large editorial typography
- calm, confident copy presentation
- image-led storytelling
- refined CTA cards instead of basic buttons
- consistent section rhythm

Every section should feel intentional and connected to the next.
