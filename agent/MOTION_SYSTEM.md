# Motion System

Use premium motion only.

Motion should feel:
- smooth
- subtle
- cinematic
- expensive
- restrained

Use:
- staggered text reveal
- slow image reveal
- soft parallax
- hover lift on cards
- subtle glow on CTAs
- scroll-triggered section reveal

Avoid:
- bouncing
- spinning
- flashy transitions
- fast cheap animations
- too much movement

Preferred timing:
- 0.8s to 1.2s for section reveals
- 0.35s to 0.5s hover transitions
- stagger 0.08s to 0.15s
- easing: power3.out or cubic-bezier luxury feel
